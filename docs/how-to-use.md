# How to use this site

## Run Docsify

```powershell
cd D:\Techriff-Project\interview-qa-docsify
npm install
npm start
```

Then open **http://localhost:3000**.

Docsify just shows the Markdown files in the browser. You do not need a build.

---

## How to practice

1. Hide the answer. Only look at the question.
2. Speak for about one minute. Talk like a person, not a textbook.
3. Then read the answer and see what you missed.
4. Answer the **cross-question** out loud. That is the part most people freeze on.
5. If you get stuck, say three short bullets: what it is, why we use it, one example.

---

## A simple way to answer any tech question

1. Say what it is in one line.
2. Say why it exists.
3. Give one example from work if you can.
4. Say when you would *not* use it.

Example:

> Dependency Injection means a class does not create its own helpers. The app gives them in. We do this so tests can swap fakes, and so we can change the database later without rewriting the controller. In ASP.NET Core, the container gives `IIncidentService` to the controller. I would not make everything transient without checking memory.

## “Tell me about yourself”

Use **now → before → next**, about 90 seconds:

1. What you do today
2. One or two projects that match this job
3. Why this role

Do not read your full CV.

---

## Cross-questions

Interviewers almost always ask one more thing:

- “Give me an example from your project.”
- “What if we skip this?”
- “How is this different from X?”
- “How would you debug it?”
- “Is there a performance cost?”

Practice those, not only the first answer.
